# zepto-sales-analytics-powerbi
Zepto sales analytics project using SQL, Power BI &amp; DAX to analyze pricing, discounts, product demand, revenue, and inventory insights.

Project Overview

The project transforms raw Zepto product data into an interactive Power BI dashboard, combining SQL-based analysis with business-focused data visualization.

3. Product & Demand Analysis

Top products by quantity sold

🔍 Key Insights

The analysis covers 4K+ products across 14 categories, highlighting pricing differences, discount strategies, high-demand products, and product-level price efficiency.

The project also examines whether higher discounts are associated with increased product demand using a product-level scatter analysis and trend line.
